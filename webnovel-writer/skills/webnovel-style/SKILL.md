# 作者风格画像

## 目标

把目标作者的**真实样本文本**提炼成一份可执行的风格画像（量化指纹 + 质性画像），写章时按画像起草、润色时按指纹校验，让成稿带上目标作者的文笔特征。

## 原则

1. **只认样本，不认记忆**：风格特征必须从用户提供的样本文本中提取并给出原文证据；禁止凭训练记忆描述"某作者的风格"——没有样本就阻断。
2. **模仿风格，不复制文本**：画像描述的是句式习惯、节奏、对白方式等抽象特征；禁止把样本中的具体语句、情节、设定、人名写进画像或后续正文。
3. 画像必须**指令化**：每条特征写成"写作时怎么做"，不是文学评论。
4. 量化归脚本（指纹），质性归 LLM（画像），两者配套。

## 环境准备

```bash
export WORKSPACE_ROOT="${CLAUDE_PROJECT_DIR:-$PWD}"
export SCRIPTS_DIR="${CLAUDE_PLUGIN_ROOT:?}/scripts"
export PROJECT_ROOT="$(python -X utf8 "${SCRIPTS_DIR}/webnovel.py" --project-root "${WORKSPACE_ROOT}" where)"
```

## 存储约定

| 文件 | 内容 |
|------|------|
| `.webnovel/style/{name}.fingerprint.json` | 量化指纹（脚本生成） |
| `.webnovel/style/{name}.profile.md` | 质性画像（LLM 生成） |
| `.webnovel/style/active.json` | 当前激活画像指针 |

## 执行流程

### Step 1：收集样本

向用户确认：
- 画像名 `{name}`（通常是作者名或书名）
- 样本文件路径（1 个或多个文本文件；也可以是本书已写的高分章节——用于固化"本书已成型风格"）

要求：
- 样本合计 ≥ 3000 字（建议 2-5 个完整章节，脚本会硬校验）
- 样本应覆盖不同场景类型（战斗/对话/过渡至少两类），单一场景提不出完整画像，向用户提示但不阻断
- **没有样本文件 → 阻断**。用户只给书名/作者名时，明确说明不能凭记忆生成画像，请其提供文本

### Step 2：提取量化指纹（脚本）

```bash
python -X utf8 "${SCRIPTS_DIR}/webnovel.py" --project-root "${PROJECT_ROOT}" style-fingerprint extract \
  --name "{name}" --files {样本文件1} {样本文件2} --activate
```

返回指标含：平均句长/句长波动、短句长句占比、平均段长、单句成段比、对白字数占比、对白平均长度、标点密度（！？…—）、万能副词密度。这些数字是画像第 2 段的事实基础。

### Step 3：生成质性画像（LLM）

通读全部样本（`Read`），结合 Step 2 指纹，按以下固定结构写画像。每条特征必须：(a) 有样本原文证据（引 1 句即可，仅作分析依据，不进入画像正文）；(b) 写成可执行指令。

```markdown
# 风格画像：{name}

## 1. 一句话风格定位
{如：短句快节奏 + 冷幽默吐槽流 + 对白推剧情}

## 2. 节奏与句式（对应指纹数据）
{平均句长 N 字上下；x% 短句制造爆点；段落 y 字内；具体指令如"高潮段连用 ≤8 字短句"}

## 3. 对白
{对白/叙述配比；对白是否承担推进职能；说话标签习惯（"xx道"还是裸对白）；口癖与语气词使用}

## 4. 描写习惯
{感官偏好（视觉系/动作系/心理系）；比喻密度与取材域；白描还是渲染；环境描写的位置与篇幅}

## 5. 叙事视角与距离
{紧贴主角内心还是冷叙述；是否插入叙述者吐槽；信息揭示习惯}

## 6. 用词色彩
{文雅/粗粝/网感/古风…；特征性词类（不列具体专名）；标点习惯（省略号/破折号怎么用）}

## 7. 章节结构习惯
{开头怎么切入；场景怎么转换；章末怎么收}

## 8. 这个作者从不做的事
{反向约束，如"从不写大段心理独白""从不解释招式原理"}

## 9. 起草指令卡（写章时直接注入的浓缩版，≤200 字）
{把 2-8 浓缩为一段命令式指引}
```

用 `Write` 保存到 `.webnovel/style/{name}.profile.md`。

### Step 4：展示与确认

把画像完整展示给用户确认；用户可修改（如"吐槽密度降一点"），按修改更新画像文件。确认后提示激活状态：

```bash
python -X utf8 "${SCRIPTS_DIR}/webnovel.py" --project-root "${PROJECT_ROOT}" style-fingerprint list
# 切换/取消：style-fingerprint activate --name {name|none}
```

### Step 5：验证

- `{name}.fingerprint.json` 与 `{name}.profile.md` 都存在
- 画像 9 段齐全，第 9 段 ≤ 200 字
- 画像中不含样本的具体人名/地名/情节

## 与写章流程的配合（已接入，无需额外操作）

- 起草：context-agent 检测到激活画像时，把画像第 9 段（起草指令卡）折进任务书第 4 段
- 润色：webnovel-write Step 4 按画像做风格对齐，并跑 `style-fingerprint compare` 出偏差报告，alignment=low 时按 off_fields 逐项修
- 多画像可随时 `activate` 切换；`activate --name none` 恢复默认风格

## 边界

- 不写正文、不改章纲
- 画像不进入 canon（设定集/state），只存 `.webnovel/style/`
- 样本文本本身不复制进任何项目文件

## 失败恢复

| 故障 | 处理 |
|------|------|
| 样本 < 3000 字 | 脚本报 SAMPLE_TOO_SMALL，请用户补样本 |
| 用户只给书名无文本 | 阻断并说明不能凭记忆生成 |
| 画像文件损坏 | 重跑 Step 3（指纹仍在则无需重提） |
| compare 报 INPUT_ERROR | 确认画像名与成稿路径 |
